# Shreya Makeup Artist - Portfolio Website

✨ A beautiful, responsive portfolio website for a professional makeup artist built with React, Vite, and Tailwind CSS.

## ✨ Features

- 🎨 Beautiful and modern UI design
- 📱 Fully responsive (mobile-first)
- ✨ Animated components with scroll effects
- 💄 Professional makeup artist portfolio
- 📸 Gallery with 6 makeup styles
- 💬 WhatsApp integration for bookings
- 📱 Floating WhatsApp button
- 🎬 YouTube video integration
- ⭐ Testimonial carousel with ratings
- 📝 Contact form with WhatsApp direct messaging
- 🌐 Social media links (Instagram, Facebook, YouTube, WhatsApp)
- 🎯 Smooth scrolling with active section tracking
- 🎪 Fun fair style gallery interactions

## 🚀 Tech Stack

- **React 18** - UI Framework
- **Vite** - Build Tool
- **Tailwind CSS** - Styling
- **Font Awesome** - Icons
- **Work Sans** - Google Font
